# Comillas Negras - Network Packet Analyzer

A simple packet sniffer built using Python and Scapy. Captures and analyzes packets, showing IPs, protocols, and payloads.

## How to Use

1. Create a virtual environment *(recommended)*:
```bash
python3 -m venv venv
source venv/bin/activate

2.Install dependencies:

bash
pip install scapy

3.Run the sniffer (you may need root):

bash
sudo python comillas_negras_sniffer.py
